별일없지 — Physical AI 생활안심 시스템 PRD

문서 버전 v1.0 · 작성일 2026-10-06
본 문서는 제품 기준 PRD입니다. 4주 개인 PoC는 이 중 거실·침실 카메라 파이프라인과 앱 연동만 검증합니다(5장 하단 참고).
주요 출력(행동)은 입력란이 비어 있어 보호자 알림, 앱 상태 표시, 야간 동선 조명 제어, 기관 대시보드 표시로 정의했습니다. (가정)

1. 문제 정의 (Problem Statement)
1.1 현재 문제
독거 고령자 가구는 사고가 없는 날에도 "평소처럼 생활하고 있는지"를 가족이나 돌봄 인력이 확인할 수단이 부족합니다.
확인은 주로 안부 전화와 정기 방문에 의존합니다. 그래서 확인 빈도는 사람의 시간에 묶여 있고, 확인과 확인 사이의 공백은 그대로 남습니다.
위험은 사고 순간보다 그 전의 생활 리듬 변화로 먼저 나타나는 경우가 많습니다. 예를 들어 늦은 기상, 활동 감소, 야간 화장실 장시간 체류 같은 신호입니다. 그런데 지금은 이런 변화를 기록하고 비교하는 체계가 없습니다.
1.2 기존 방식의 한계
방식	한계
안부 전화·방문	인력과 시간에 비례해 비용 증가, 확인 사이 공백 발생
실내 CCTV	원본 영상 상시 노출로 사생활 침해, 고령자 거부감, 보호자가 직접 영상을 봐야 함
PIR 단독 센서	"08:31 움직임"만 기록. 휴식·수면·외출 등 행동의 의미를 구분하지 못함
웨어러블·응급버튼	착용·충전·조작을 고령자에게 요구. 미착용 시 무용지물
1.3 핵심 가치

"고령자는 평소처럼 생활하고, 기술은 뒤에서 조용히 안전을 보조한다."

고령자 조작 0회: 착용·버튼·앱 조작을 요구하지 않습니다.
영상 대신 생활 신호: 보호자에게는 "07:42 거실에서 활동 시작" 같은 의미 단위 이벤트만 전달합니다.
평소 대비 변화 감지: 개인별 기준선과 비교해 "확인이 필요한 날"만 알립니다.
확정 진단 금지: "식사를 안 했습니다", "낙상했습니다" 대신 "확인이 필요한 변화가 있어요"로 표현합니다.
1.4 왜 AI가 필요한가
PIR은 움직임 유무만 알고, 자세(서기·앉기·눕기)와 위치(소파·침대·바닥)를 구분하지 못합니다. 휴식, 수면 추정, 바닥에 누운 상태 같은 판단에는 카메라 기반 사람 검출과 Pose 추정이 필요합니다.
프라이버시를 지키려면 영상을 사람이 보는 대신 기계가 현장에서 해석하고 폐기해야 합니다. 이 해석 단계가 곧 Edge AI의 역할입니다.
생활 리듬은 사람마다 다릅니다. 고정 임계값(예: 180분 무활동)으로는 오알림과 미탐지가 함께 발생하므로, 장기적으로 개인별 기준선 학습이 필요합니다.

공간별 장치 배치

공간	장치	수집 신호
거실·식탁	Edge 카메라 #1	활동 / 휴식 / 시야 밖
침실	Edge 카메라 #2 (IR 지원)	침대 휴식 추정, 야간 침대 이탈

화장실	문 센서 + PIR (카메라 미설치)	입실·퇴실, 장시간 체류

단계별 흐름

단계	내용
1. 설치	설치 기사가 1시간 이내에 장치 4종을 설치합니다. 앱에서 카메라 화면을 설치 시 1회만 보며 Zone(소파·식탁·침대·바닥)을 지정하고, 이후 영상 보기 기능은 비활성화됩니다. 피보호자와 보호자는 서면 동의서에 서명합니다.
2. 데이터 수집	카메라는 5~10 FPS로 프레임을 Edge 장치 메모리에서만 처리하고 즉시 폐기합니다. ESP32 센서는 문 열림·움직임 이벤트와 10분 주기 heartbeat를 Cloud로 전송합니다.
3. 분석	Edge: 사람 검출 → Pose 17점 추정 → Zone 매칭 → 체류 시간 계산 → 상태 머신이 ACTIVE / REST / BED_REST / NOT_IN_VIEW / FLOOR_LYING을 판단합니다. Cloud: 10분마다 하루 이벤트를 집계하고 최근 14일 개인 기준선(첫 활동 시각, 오전 활동 시간, 야간 화장실 횟수 등)과 비교합니다.
4. 판단 결과 생성	상태 전환 시점에만 의미 이벤트를 생성합니다. 예: 07:42 ACTIVE(거실), 23:10~06:35 BED_REST, 09:30 외출 추정. 하루 상태는 NORMAL / CHECK / EMERGENCY 중 하나로 판정합니다.
5. 장치·사용자 제어	① 야간(22:00~06:00) 침대 이탈 감지 시 침실→화장실 동선 LED를 자동 점등하고, 침대 복귀 또는 10분 경과 시 소등합니다. ② CHECK 전환 시 보호자에게 FCM 푸시를 보냅니다. ③ 화장실 체류가 기준을 넘거나 바닥에 누운 상태가 지속되면 EMERGENCY 후보로 보고 보호자와 담당 생활지원사에게 동시에 알립니다.
6. 결과 확인·후속 행동	보호자는 앱 Timeline에서 "오늘 오전 활동이 평소보다 적어요"를 확인하고 전화합니다. 연락이 되지 않으면 생활지원사 방문을 요청합니다. 생활지원사는 대시보드의 CHECK 가구부터 우선 연락해 정기 확인 업무를 줄입니다.

판정: 조건부 GO

100가구 파일럿 단독으로는 회수기간이 약 45개월(3.8년)로 사업성이 약합니다. 초기 AI 개발비가 적은 가구 수에 집중되기 때문입니다. 파일럿의 목적은 수익이 아니라 KPI 검증(오알림 가구당 주 1회 이하, 정기 확인 시간 50% 감소)으로 정의해야 합니다.
500가구 이상에서 회수기간이 약 14개월로 줄어 사업성이 성립합니다. 개발비는 고정이고 절감액은 가구 수에 비례하기 때문입니다.
가장 민감한 가정은 "정기 확인 시간 50% 감소"입니다. 이 값이 25%로 떨어지면 시나리오 B의 월 순 절감액은 약 1,220만 원으로 줄고, 회수기간은 약 23개월로 늘어납니다. 파일럿에서 이 수치를 가장 먼저 실측해야 합니다.
